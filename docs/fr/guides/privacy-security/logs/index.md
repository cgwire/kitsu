# Pages de journaux

<!-- #region body -->

Les responsables de studio peuvent utiliser les pages de journaux dans `Main Menu > Admin > Logs` pour renforcer la sécurité ou auditer l’activité des utilisateurs afin de résoudre les problèmes.

## Journaux d’activité

Les journaux d’activité répertorient toutes les requêtes API :

![Page des journaux d’activité](/fr/img/activitylogs.jpg)

Il est possible de filtrer les journaux par jour et par utilisateur.

## Journaux de connexion

Les journaux de connexion offrent aux administrateurs une meilleure visibilité sur l’accès aux comptes au sein de leur organisation :

![Page des journaux de connexion](/fr/img/loginlogs.jpg)

Vous pouvez les utiliser pour voir qui s’est connecté, comment et quand. Le journal permet de filtrer par date et par personne afin d’examiner une activité spécifique, et inclut une pagination pour parcourir les ensembles de données volumineux.

## Journaux d’état des fichiers d’aperçu

Le téléversement de fichiers d’aperçu peut être délicat pour les vidéos volumineuses. Cette page répertorie donc tous les fichiers d’aperçu dans un état intermédiaire : en cours de traitement ou défectueux.

![Page des journaux d’état des fichiers d’aperçu](/fr/img/previewlogs.jpg)

Elle indique combien de fichiers d’aperçu sont en cours de traitement, ou quels téléversements de fichiers n’ont pas pu être terminés et pourquoi.

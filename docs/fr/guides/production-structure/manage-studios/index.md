# Gérer les libellés des studios

<iframe width="560" height="315" src="https://www.youtube.com/embed/u-KI4g55dFQ?si=9NbdBH_bLRfK5cC0" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>

<!-- #region body -->

Un studio est un libellé utilisé pour organiser les équipes dans les productions comportant plusieurs studios ou sites.

Vous pouvez l’utiliser pour filtrer les tâches, les plannings et les équipes par studio.

<!-- #region setup -->

Accédez à `Menu principal > Administration > Studios` pour ouvrir la page `Studios`.

![page des studios](/fr/guides/production-structure/manage-studios/images/0.png)

## Créer un studio

Pour créer un nouveau studio, cliquez sur le bouton `Ajouter un studio` :

![bouton de création d’un studio](/fr/guides/production-structure/manage-studios/images/1.png)

Une boîte de dialogue s’ouvrira pour ajouter un nom au studio et choisir une couleur :  

![fenêtre modale de création d’un studio](/fr/guides/production-structure/manage-studios/images/2.png)

Cliquez simplement sur `Confirmer` pour enregistrer.

<!-- #endregion setup -->

## Mettre à jour un studio

Survolez la ligne du studio que vous souhaitez modifier dans la liste et cliquez sur l’icône `Modifier` :  

![bouton de mise à jour d’un studio](/fr/guides/production-structure/manage-studios/images/3.png)

## Ajouter des personnes à un studio

Sur la page `Personnes` (`Menu principal > Administration > Personnes`), cliquez sur un utilisateur pour modifier son appartenance à un studio.

![](/fr/guides/production-structure/manage-studios/images/5.png)

De même, vous pouvez retirer une personne d’un studio en sélectionnant l’option `Aucun studio`.

## Filtrer les vues par studio

Les pages `Planning de l’équipe` et `Toutes les tâches` affichent un filtre de studio que vous pouvez utiliser pour filtrer les tâches.

![](/fr/guides/production-structure/manage-studios/images/6.png)

Sélectionnez simplement le studio souhaité dans le menu déroulant.

## Supprimer un studio

Survolez la ligne du studio que vous souhaitez supprimer dans la liste et cliquez sur l’icône `Supprimer` :  

![bouton de suppression d’un studio](/fr/guides/production-structure/manage-studios/images/4.png)

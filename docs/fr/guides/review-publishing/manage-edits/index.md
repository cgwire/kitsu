# Gérer les montages

<!-- #region body -->

Un montage est un type d’entité traçable (comme un asset ou un plan) qui représente un montage vidéo. Il peut s’agir, par exemple, de votre film complet, de plusieurs bandes-annonces ou de différentes versions du montage, comme le premier montage, le montage final ou le mixage.

Voici à quoi il peut servir :

- Suivre les tâches au niveau du montage lorsque plusieurs montages doivent passer par plusieurs étapes de validation (par exemple, Premier montage → Montage final → Mixage)
- Attribuer des tâches, effectuer des révisions et modifier le statut de chaque montage, comme pour les assets/plans
- Ajouter des colonnes de métadonnées personnalisées et des descriptions
- Définir/modifier la résolution par montage en fonction des exigences de livraison

## Créer un montage

<!-- #region setup -->


::: warning
Par défaut, la page **Edit** ne s’affichera pas tant que vous n’aurez pas défini de types de tâches pour celle-ci dans votre **bibliothèque de production** (page des paramètres).
:::

Pour utiliser cette page, vous devez d’abord créer un type de tâche dédié dans votre **bibliothèque globale** avec l’attribut **Edit**.

Consultez la section [Créer un nouveau type de tâche](/fr/guides/task-configuration/managing-task-types/#creating-a-new-task-type) pour créer un nouveau **type de tâche**.

Une fois vos **types de tâches** créés dans votre **bibliothèque globale**, ajoutez-les à votre **bibliothèque de production**. Le menu déroulant de navigation affichera alors **Edit**.

![Navigation Edit](/fr/img/getting-started/drop_down_menu_edit.png)

Cette nouvelle page fonctionne comme la page globale des assets et des plans. Vous pouvez ajouter vos montages à l’aide du bouton `+ New edit`.

Vous pouvez attribuer des tâches, effectuer la révision, modifier le statut, etc.

Vous pouvez ajouter une colonne de métadonnées, renseigner la description, etc.

::: tip
Selon vos livrables, vous pouvez également modifier la résolution par **Edit**.
:::

::: warning
La page de détails diffère de celle des autres entités.

Comme **Edit** se concentre sur une vidéo longue spécifique, la page de détails ressemble davantage à la page de détails des commentaires.
:::

Vous pouvez **renommer** et **supprimer** l’entité Edit sur cette page, comme pour les entités asset et plan.

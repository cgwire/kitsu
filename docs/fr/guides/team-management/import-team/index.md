# Importer votre équipe

<!-- #region body -->

Il est fort probable que vous ayez déjà une liste de vos employés quelque part.

Vous avez trois façons de les importer dans Kitsu :

1. Importer directement un fichier tableur `.csv`
2. [Copier-coller vos données directement dans Kitsu](/fr/guides/team-management/managing-teams/)
3. Utiliser l’[API pour développeurs](https://dev.kitsu.cloud/guides/team-management.html#inviting-and-managing-users)

## Ajouter des employés à partir d’un fichier tableur CSV

Commencez par enregistrer votre feuille de calcul au format `.csv`.

Ensuite, retournez sur la page des personnes dans Kitsu et cliquez sur l’icône **Importer** :

![Icône d’importation](/fr/img/getting-started/import.png)

Une fenêtre contextuelle **Importer des données depuis un fichier CSV** s’ouvrira. Cliquez sur **Parcourir** pour sélectionner votre fichier `.csv`.

![Importer un fichier csv](/fr/img/getting-started/import_csv_people.png)

Pour voir le résultat, cliquez sur le bouton **Aperçu**.

Vous pouvez vérifier et ajuster les noms des colonnes à l’aide de l’aperçu de vos données.

**Remarque :** La colonne **Rôle** n’est pas obligatoire.

![Importer des données par copier-coller](/fr/img/getting-started/import_preview_data_people.png)

Une fois que tout semble correct, cliquez sur le bouton **Confirmer** pour importer vos données dans Kitsu.

Toutes vos personnes sont maintenant importées dans Kitsu.

![Importer des données par copier-coller](/fr/img/getting-started/import_result_people.png)

# Breakdown et casting

<!-- #region body -->

Remplir le breakdown vous aide à assembler les plans. Avec le breakdown, vous disposez de tous les détails des assets à ajouter pour créer votre plan, et nous sommes certains de ne rien omettre.

Dans le menu déroulant, choisissez **BREAKDOWN**.

![Menu déroulant breakdown](/fr/img/getting-started/drop_down_menu_breakdown.png)

## Créer une liste de breakdown

<!-- #region setup -->

Sur la gauche de la page de breakdown se trouve le menu épisode/séquence/plan (1) : vous pouvez choisir parmi ceux que vous avez créés. Sur la partie droite de l’écran se trouvent tous les assets créés et disponibles pour cette production (pack principal et épisodes) (3). De plus, dans la section centrale se trouve votre sélection pour le plan (2).

![Page de breakdown](/fr/img/getting-started/breakdown_general_empty.png)

Vous devez maintenant sélectionner le plan que vous souhaitez caster.

Vous pouvez afficher les assets sous forme de texte si vous n’avez pas encore de miniatures, ou augmenter la taille des miniatures.

![Affichage texte de la page de breakdown](/fr/img/getting-started/breakdown_text_display.png)

Vous pouvez également constater qu’un asset doit être ajouté à la liste pendant votre breakdown.

Vous pouvez créer un nouvel asset directement depuis la page de breakdown. Cliquez sur le **+** à droite de **Tous les assets disponibles**.

![Créer un asset depuis la page de breakdown](/fr/img/getting-started/breakdown_create_asset.png)

Vous pouvez également choisir plusieurs plans à la fois. Cliquez sur le premier plan, maintenez la touche **Maj** enfoncée, puis cliquez sur le dernier plan de votre sélection.

![Sélection groupée globale de la page de breakdown](/fr/img/getting-started/breakdown_general_bulk_select.png)

Cliquez ensuite sur les assets que vous souhaitez
attribuer : personnages, décors, ... depuis la partie droite (3).
Si vous avez sélectionné plusieurs plans, votre sélection est appliquée à tous les plans concernés.

Copiez un plan rempli d’assets et collez cette sélection d’assets dans un autre plan.

Vous pouvez voir **+1** ou **+10** lorsque vous passez sur l’asset. Il s’agit du nombre
de fois où vous ajoutez cet asset, et vous pouvez cliquer dessus autant de fois que nécessaire.

![Ajouter un asset dans le breakdown](/fr/img/getting-started/breakdown_add_asset.png)

Vous pouvez également lier tous vos assets à des épisodes d’une série TV sans préciser de séquence ou de plan.

![Asset lié à un épisode dans le breakdown](/fr/img/getting-started/breakdown_episode.png)

De cette manière, vous pouvez lier tous vos assets à un ou plusieurs épisodes avant l’étape du storyboard/animatique.

Vous pouvez maintenant voir l’asset au centre de l’écran (2). À côté
du nom de l’asset se trouve le nombre de fois où il a été ajouté. Dans cet
exemple, nous avons ajouté deux fois l’asset personnage Llama.


Si vous ajoutez deux fois un asset par erreur, vous devez vous rendre dans la partie centrale de l’écran pour sélectionner les assets de ce plan (2). Depuis cet emplacement, cliquez sur
**-1**. Lorsque vous avez terminé ce plan, passez aux autres plans.
Votre sélection est automatiquement enregistrée.

![Supprimer un asset du breakdown](/fr/img/getting-started/breakdown_remove_asset.png)

Si un nouvel asset est créé pendant le storyboard, retournez sur la page des assets
(en utilisant le menu déroulant) et créez les assets nécessaires. Les tâches créées précédemment sont immédiatement appliquées à ces nouveaux
assets. Cependant, vous devez effectuer l’attribution, puis vous pouvez
continuer le breakdown.

Votre page de **Breakdown** devrait maintenant ressembler à ceci.

![Ajouter des assets en groupe dans le breakdown](/fr/img/getting-started/breakdown_general_bulk_select_full.png)

Vous pouvez également créer une liste de breakdown pour vos assets si vous devez les assembler et suivre leurs différentes parties.

Dans le coin supérieur gauche de l’écran, choisissez **asset** dans le menu déroulant situé sous **POUR**.

![Menu des assets du breakdown](/fr/img/getting-started/breakdown_asset_menu.png)

Vous pouvez maintenant accéder à un deuxième menu déroulant pour choisir le type de votre asset : **Personnage**, **Environnement**, **Accessoires**, **FX**, ...

![Type d’asset du breakdown](/fr/img/getting-started/breakdown_asset_menu_type.png)

Vous pouvez remplir la page de breakdown des assets de la même manière que pour les plans. Commencez par sélectionner un ou plusieurs assets dans la partie gauche, puis ajoutez les éléments de la partie droite.

::: details Créer une liste de breakdown à partir d’un fichier CSV

Vous disposez peut-être déjà de votre liste de breakdown dans un tableur. Avec Kitsu, vous avez deux façons de l’importer : la première consiste à importer directement un fichier .csv, et la seconde à copier-coller vos données directement dans Kitsu.

Commencez par enregistrer votre tableur au format `.csv` en suivant les recommandations de Kitsu.

Cliquez sur le bouton **importer** ![Bouton Importer](/fr/img/getting-started/import.png)

Une fenêtre contextuelle **Importer des données depuis un CSV** s’ouvre. Cliquez sur **Parcourir** pour sélectionner votre fichier `.csv`.

![Importer un fichier CSV de breakdown](/fr/img/getting-started/import_breakdown_csv_file.png)

Pour voir le résultat, cliquez sur le bouton **Aperçu**.

Vous pouvez vérifier et ajuster le nom des colonnes en affichant un aperçu de vos données.

NB : la colonne **Episode** est obligatoire uniquement pour une production de type **TV Show**.

![Aperçu de l’importation du breakdown](/fr/img/getting-started/import_breakdown_preview.png)

Une fois que tout est correct, cliquez sur le bouton **Confirmer** pour importer vos données dans Kitsu.

Votre breakdown est maintenant importé dans Kitsu.

![Aperçu de l’importation du breakdown](/fr/img/getting-started/breakdown_general_bulk_select_full.png)
:::

::: details Créer une liste de breakdown en copiant/collant un fichier tableur

Ouvrez votre tableur, sélectionnez vos données, puis copiez-les.

![Copier les données pour l’importation](/fr/img/getting-started/import_copypas_breakdown.png)

Revenez ensuite à la page de breakdown dans Kitsu et cliquez sur l’icône **Importer**
![Icône Importer](/fr/img/getting-started/import.png).

Une fenêtre contextuelle **Importer des données depuis un CSV** s’ouvre ; cliquez sur l’onglet **Coller des données CSV**.

![Onglet de copie-collage des données d’importation](/fr/img/getting-started//import_breakdown_csv_file.png)
 
Vous pouvez coller les données sélectionnées précédemment et voir le résultat avec le bouton **Aperçu**.
 
![Données copiées-collées pour l’importation](/fr/img/getting-started/import_breakdown_preview.png)
 
Vous pouvez vérifier et ajuster le nom des colonnes en affichant un aperçu de vos données.
 
NB : la colonne **Episode** est obligatoire uniquement pour une production de type **TV Show**.
 
![Données copiées-collées pour l’importation](/fr/img/getting-started/import_breakdown_preview.png)

Une fois que tout est correct, cliquez sur le bouton **Confirmer** pour importer vos données dans Kitsu.

Tous vos assets sont maintenant importés dans Kitsu.

![Données copiées-collées pour l’importation](/fr/img/getting-started/breakdown_general_bulk_select_full.png)
:::

## Caster depuis la bibliothèque d’assets

Il est également possible de caster des assets depuis la **bibliothèque d’assets** globale dans votre production. Cela vous permet de caster un asset existant, sans avoir à le recréer pour chaque production.

![Affichage de la bibliothèque d’assets](/fr/img/getting-started/asset_library_display.png)

Pour afficher les assets extérieurs à votre production depuis la bibliothèque d’assets, cliquez sur le bouton **Afficher la bibliothèque** (1).

Les assets de la bibliothèque d’assets globale apparaîtront et seront signalés par une bordure jaune (2). Ils peuvent ensuite être castés dans votre breakdown exactement comme les autres assets.

![Vue de la bibliothèque d’assets](/fr/img/getting-started/asset_library_view.png)

De retour sur la page des assets de votre production, vous pouvez choisir d’afficher les assets globaux qui ont été castés dans votre production en activant le bouton **Afficher la bibliothèque** (1). Ces assets seront signalés en jaune, indiquant qu’ils proviennent de la bibliothèque d’assets globale et non de votre production actuelle (2).

Pour en savoir plus sur la bibliothèque d’assets, [consultez la section dédiée](/fr/guides/production/manage-assets/#asset-library).

# 2Dプロダクション向けKitsu

[[スタイルに特化したパイプラインの機能を紹介するプロダクションスタイルページのコンセプト]]

Kitsuは、かなり標準的なプロダクション追跡データモデルを中心に構築されており、ほとんどの2Dスタジオではデフォルト設定を調整して使用します。一般的には次のように構成されます。

## アセットタイプ

アセットは通常、カテゴリ別にグループ化されます。2D作品で一般的なものは次のとおりです。

- **キャラクター**
- **プロップ**
- **セット／背景**（「デコール」と呼ばれることもあります — CG Wireのフランス語圏に由来するKitsuのデフォルト用語です）
- **FX**（再利用可能なエフェクト要素などのために、2Dでも独立したアセットタイプとして扱われることがあります）

各アセットには独自のタスクリストがあり、アセットタスクはショットタスクとは別に追跡されます。

## タイプ

タスクタイプは、**アセットタスク**と**ショットタスク**の2つの系統に分かれます。

**アセットタスクタイプ（2D向けのデフォルト）：**

- コンセプト／デザイン
- 純粋な2Dではモデリングは省略されますが、代わりに「ターンアラウンド」や「モデルパック」タスクを残すスタジオもあります
- カラー／スタイル（カラースクリプト、パレット）
- リギング（カットアウト／Toon Boomリグを使用する場合）

**ショットタスクタイプ（一般的な2Dパイプライン）：**

- ストーリーボード
- レイアウト（レイアウトポーズ／レイアウトに分割されることもあります）
- アニメーション（スタジオが個別に追跡する場合、ラフアニメーション／クリーンアップに分割されることがよくあります）
- 中割り（アニメーションに統合されることもあります）
- コンポジティング
- FX
- ライティング（フラットな2Dではあまり一般的ではなく、2D／3Dハイブリッドでより関連性があります）

## タスクステータス

Kitsuには、誰でも拡張できるデフォルトのステータスセットが用意されています。

- **未着手**
- **作業中（WIP）**
- **承認待ち（Pending）**
- **リテイク**（差し戻し）
- **完了**

スタジオでは、「保留」、「省略」（作品からカット）、「待機中」など、依存関係によるブロックを表すカスタムステータスを追加することがよくあります。

## エピソードとシーケンス

2Dシリーズ制作では、通常、階層は **エピソード → シーケンス → ショット** となり、アセットはキャスティングを通じてショットにリンクされます。このエピソード階層は、Sequence → Shotだけを使用することが多い映画や短編のパイプラインと比べ、テレビアニメーションスタジオで特によく使用される機能のひとつです。

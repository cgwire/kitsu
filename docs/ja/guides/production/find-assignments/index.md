# 担当タスクの管理

<!-- #region body -->

## 「マイタスク」ページ

**マイタスク**ページは、担当タスクを管理するためのメイン画面で、ログインすると自動的に開きます。

ここでは、自分に割り当てられたタスクの一覧と、いくつかの重要な情報を確認できます。いわば、やることリストのようなものです。

デフォルトでは、一覧は優先度順に並んでいるため、上部に表示されるタスクほど、先に対応することが推奨されます。

### 確認できる主な情報：

- **制作**：タスクが関連付けられているプロジェクト。
- **エンティティ**：自分に割り当てられた具体的なアセットまたはショット。
- **見積もりと期間**：タスクに関する時間情報。
- **期限**：タスクを完了する期限。
- **ステータス**と**優先度**：タスクの緊急度を把握するための重要な情報。

![マイタスクページ](/ja/img/getting-started/my_task_page.png)

タスクの詳細を表示するには、**ステータス**をクリックしてコメントパネルを開きます。ここでタスクにコメントしたり、必要に応じて新しいリビジョンを公開したりできます。

![スーパーバイザーのTo Do詳細ページ](/ja/img/getting-started/supervisor_todo_page_detail.png)

### 並べ替えとフィルタリング：

- **表示**ドロップダウンでは、**すべてのタスク**を表示するか、**今週が期限のタスク**に絞り込むかを選択できます。
- **並べ替え**ドロップダウンでは、タスクを**名前**、**優先度**、**ステータス**、**見積もり**、または**最後のコメント**で並べ替えられます。
- これらのフィルターに加えて、**制作**、**タスクタイプ**、**ステータス**などの条件を使用してタスク一覧を絞り込めます。また、検索ボックスを使って特定のタスクを検索することもできます。

![タスクの並べ替えとフィルタリング](/ja/img/getting-started/mytask_sort.png)

### マイタスクへのアクセス

**マイタスク**には、次の方法でアクセスできます。
- 画面上部のショートカット。
- メインメニューの**ユーザー**セクションにある**マイタスク**。
- Kitsuロゴをクリックする。![メインメニュー](/ja/img/getting-started/main_button.png)

## ボードビュー

ボードビューを使用すると、複数のタスクを各ステータス列にドラッグ＆ドロップして、ステータスをすばやく更新できます。

**ボードタブ**には、ステータスごとに整理されたタスクが列形式で表示されます。各タスクカードには次の情報が含まれます。

- サムネイル
- タスクタイプ名
- エンティティ名

![スーパーバイザーのTo Do詳細ページ（ボード）](/ja/img/getting-started/supervisor_todo_page_detail_board.png)

- カードをクリックすると、右側にパネルが開き、コメントを確認または追加できます。
- タスクのステータスを更新するには、目的の列にドラッグします。

## カレンダービュー

**カレンダービュー**には、タスクの**開始日**と**期限**に基づいてタスクが表示されます。複数日にわたるタスクは、カレンダー上でその期間に沿って表示されます。

![カレンダービュー](/ja/img/getting-started/artist_calendar_page.png)

- タスクをクリックすると、右側のパネルが開き、更新やコメントを行えます。
- 他のビューと同様に、ここでもタスクの並べ替えやフィルタリングができます。

## 「タスクタイプ」ページ

<!-- #region for-supervisors -->

スーパーバイザーには、通常、自分の部署の監督に加えてタスクも割り当てられます。自分の作業を完了しながら、チームの管理も行う必要があります。

割り当てと見積もりが完了したら、日々の運用に集中できます。自分の部署のタスク全体を簡単に確認するには、任意のページからタスクタイプ名をクリックします。

詳細ページを開いたら、まず**タスクをコンタクトシートとして表示**![タスクをコンタクトシートとして表示](/ja/img/getting-started/contact_sheet.png)ボタンをクリックします。

![コンタクトシートとして表示したタスクタイプ](/ja/img/getting-started/task_type_contact_sheet.png)

これで、組み込みのフィルターを使用して、対応が必要なタスクに簡単に絞り込めます。たとえば、まだ完了していないタスクだけを表示したいとします。この場合、**-完了**ステータスでタスクをフィルタリングし、さらに**期限ステータス**フィルターを追加して、**今週が期限のタスク**を表示できます。

![コンタクトシートとしてフィルタリングしたタスクタイプ](/ja/img/getting-started/task_type_contact_sheet_filtered.png)

フィルターは簡単に有効化または無効化できるため、必要な情報にすばやく絞り込めます。

::: tip
タスクの詳細を確認する必要がある場合は、その名前をクリックして右側のコメントパネルを開きます。

![コンタクトシートとしてフィルタリングしたタスクタイプ](/ja/img/getting-started/task_type_contact_sheet_panel.png)
:::

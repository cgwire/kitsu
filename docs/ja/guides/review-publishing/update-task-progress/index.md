# タスクの進捗を更新する

<!-- #region body -->

タスクのステータスは、タスクの現在の状態や進捗を示す指標です。

ボードを使用すると、タスクの現在のステータスを一目で簡単に確認でき、ステータスが変更された際にコメントを追加してチームメンバーに知らせることができます。

タスクを進めたら、そのステータスをチームに更新して知らせましょう。

## タスクのステータスを更新する

1. **マイタスク**ページまたは該当するアセットページで、タスクの**ステータス**アイコンをクリックします。

![ステータスのスクリーンショット](/ja/img/getting-started/shot_status.png)

右側にパネルが表示され、コメントの入力、ステータスの変更、ファイルの添付を行えます。

![コメントパネル](/ja/img/getting-started/comment_panel.png)

**コメントパネル**は2つのタブに分かれています。
- コメントを投稿
- リビジョンを公開

2. 更新内容を伝えたり質問したりするためにコメントを追加します。コメントでは**Markdown**を使用できます。Markdownは、プレーンテキストをシンプルで読みやすい形に整形するためのマークアップ言語です。見出し、リスト、太字や斜体のテキスト、リンクなど、さまざまな基本的な書式要素を追加できます。具体的な構文については、Markdownガイドのウェブサイトを参照してください：[Markdownガイド](https://www.markdownguide.org/basic-syntax/)。

3. **コメントを投稿**タブで、ステータスを（例：「準備完了」から「作業中」へ）変更します。

![ステータスの変更](/ja/img/getting-started/changing_status.png)

![ステータスリスト](/ja/img/getting-started/status_list.png)

4. **投稿**をクリックして変更を保存します。

**履歴**ボタンをクリックして**編集**を選択すると、直近のコメントを編集できます。

![編集ボタン](/ja/img/getting-started/edit_button.png)

## チームメンバーにタグを付ける

コメント内でチームメンバーに**タグ**を付けて、直接通知することもできます。これを行うには`@`を入力すると、チームメンバーの一覧を含むサブメニューが開きます。通知したい相手を選択し、コメントを送信すると、その相手に通知が届きます。

![メンバーにタグを付ける](/ja/img/getting-started/tag_team.png)

`@`に続けて部署名を入力すると、部署全体に**タグ**を付けることもできます。

![部署にタグを付ける](/ja/img/getting-started/tag_department.png)

## チェックリストを追加する

独立したタスクにするほどではない細かな項目を管理するために、チェックリスト項目を追加することもできます。コメントに**チェックリスト**を追加するには、**チェックリストを追加**ボタンをクリックします。チェックリストの最初の項目が表示されます。

![チェックリストを追加](/ja/img/getting-started/add_checklist.png)

**Enter**キーを押すか、もう一度ボタンをクリックしてチェックリスト項目を追加し、それぞれに名前を付けます。

![チェックリスト](/ja/img/getting-started/checklist_detailed.png)

## 添付ファイルを追加する

画像としてファイルを添付するには、**添付ファイルを追加**ボタンをクリックします。

![添付ファイルを追加（簡易）](/ja/img/getting-started/attachment_snapshot.png)

**ハードドライブからファイル**を選択するか、**スクリーンショット**を貼り付けます。

![添付ファイルのスナップショット](/ja/img/getting-started/add_attachmen_simplet.png)

**添付ファイルとしてファイルを追加**をクリックして、添付ファイルを確定します。

## ステータスを一括変更する

複数のタスクのステータスを一度に変更することもできます。

**Ctrl / Cmd**または**Shift**を押しながら、対象に含める複数のショットまたはアセットを選択します。

次に、アクションメニューの**ステータスを変更**セクションに移動します。

![アクションメニューのステータス](/ja/img/getting-started/blue_menu_status.png)

選択したタスクの新しいステータスを選択します（1）。選択したすべてのタスクにコメントを追加することもできます（2）。**確定**ボタンで新しいステータスを保存します。

![一括でステータスを変更](/ja/img/getting-started/change_status_batch.png)

![メタデータ列の並べ替え](/ja/img/getting-started/custom_column_sortby.png)

## コメントを削除する

コメントを削除するには、右上隅のシェブロンアイコンをクリックして`削除`を選択します。

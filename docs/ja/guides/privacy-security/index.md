# プライバシーとセキュリティ

1. [認証](/ja/guides/privacy-security/authentication/) - パスワードポリシーや二要素認証（TOTP、メールOTP、またはFIDOセキュリティキー）など、ユーザーのKitsuへのサインイン方法を管理します。
1. [ログ](/ja/guides/privacy-security/logs/) - ログインおよびアクティビティログを確認して、Kitsuインスタンスにいつ誰がアクセスしたかを追跡します。

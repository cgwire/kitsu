# ログページ

<!-- #region body -->

Studioマネージャーは、セキュリティの強化や問題のトラブルシューティングにおけるユーザーアクティビティの監査のために、`Main Menu > Admin > Logs` でログページを利用できます。

## アクティビティログ

アクティビティログには、すべてのAPIリクエストが一覧表示されます。

![アクティビティログページ](/ja/img/activitylogs.jpg)

ログは日付とユーザーごとにフィルタリングできます。

## ログインログ

ログインログを使用すると、管理者は組織全体のアカウントアクセスをより詳細に把握できます。

![ログインログページ](/ja/img/loginlogs.jpg)

誰が、どのように、いつログインしたかを確認できます。ログは日付とユーザーによるフィルタリングに対応しており、特定のアクティビティを調査できます。また、大規模なデータセットを移動するためのページネーションも含まれています。

## プレビューファイルステータスログ

大容量の動画ではプレビューファイルのアップロードが難しい場合があるため、このページには処理中または破損している中間状態のプレビューファイルがすべて一覧表示されます。

![プレビューファイルステータスログページ](/ja/img/previewlogs.jpg)

処理中のプレビューファイル数や、アップロードが完了せず失敗したファイルとその理由を確認できます。

# チームをインポートする

<!-- #region body -->

すでに従業員のリストをどこかにお持ちかと思います。

Kitsu にインポートする方法は3つあります。

1. `.csv` スプレッドシートファイルを直接インポートする
2. [データを Kitsu に直接コピー＆ペーストする](/ja/guides/team-management/managing-teams/)
3. [Developer API](https://dev.kitsu.cloud/guides/team-management.html#inviting-and-managing-users)を使用する

## CSV スプレッドシートファイルから従業員を追加する

まず、スプレッドシートを `.csv` ファイルとして保存します。

次に、Kitsu の People ページに戻り、**Import** アイコンをクリックします。

![Import Icon](/ja/img/getting-started/import.png)

**Import data from a CSV** ポップアップウィンドウが開きます。**Browse** をクリックして `.csv` ファイルを選択します。

![Import csv file](/ja/img/getting-started/import_csv_people.png)

結果を確認するには、**Preview** ボタンをクリックします。

データのプレビューを使用して、列名を確認および調整できます。

**注:** **Role** 列は必須ではありません。

![Import data copy paste data](/ja/img/getting-started/import_preview_data_people.png)

すべて問題なければ、**Confirm** ボタンをクリックしてデータを Kitsu にインポートします。

これで、すべてのメンバーが Kitsu にインポートされました。

![Import data copy paste data](/ja/img/getting-started/import_result_people.png)
